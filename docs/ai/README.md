# AI Development Context

This directory stores durable project context for AI-assisted and human development.

It is intentionally separate from `ai_skills/`:

- `docs/ai/` explains what the project is, its current architecture, and current state.
- `ai_skills/` explains how to perform recurring classes of development tasks.
- `ai_tools/` contains small project-specific validation and inspection utilities.

Start with:

1. `PROJECT_CONTEXT.md`
2. `CURRENT_STATE.md`
3. `CODING_RULES.md`
